* **브랜치**: `feature/app-manager-account`
* **주요 작업 내용** (11/27 회의 피드백 반영):

  1. **담당자 로그인**:
     * 서버에 미리 넣어 둔 계정(manager1 · manager2 · admin)으로 로그인, 자동 로그인(`expo-secure-store`), 로그아웃 확인 창.
     * 로그인한 담당자의 담당 차량만 목록에 표시, 계정 탭에 담당 구역·차량·연락처 표시.

  2. **메시지 탭 (담당자 알림)**:
     * 10초마다 알림 조회, 안 읽은 알림이 있으면 탭에 파란 점, 출발·고장 신고는 토스트로 안내.
     * 알림 목록: 전체 / 출발 / 도착 / 차량 이상 필터, 오늘·어제·그 전 묶음, 누르면 차량 상세로 이동.
     * 알림 규칙: 고장 신고는 차량 담당자 모두, 출발·도착은 그 운행의 알림 받을 담당자에게만. 둘째 줄에 보낸 사람(운행시킨 사람·신고한 사람) 이름·연락처 표시.

  3. **목적지 선택 (지도 핀 방식)**:
     * 지도를 움직여 가운데 핀으로 목적지 선택 → 경로 미리보기(거리·예상 소요) → 목적지 이름·알림 받을 담당자 선택 → 출발.
     * 고정 지점 목록 방식(작업 경로 설정·지점 선택 화면, 임시 지점 데이터) 삭제.
     * 작업 중 차량 상세 지도에 확정 경로선(청록-남색) 표시, 주행 중에는 지도가 차량을 따라감.

  4. **주행·도착**:
     * 서버 연동 전 확인용 주행 흉내(`src/mocks/driving.ts`): 경로를 따라 이동 → 도착 처리 → 도착 알림. (도로 보정 없이 'ㄱ'자 경로)
     * 도착하면 앱 어느 화면에서나 도착 확인 창(목적지·도착 시각·걸린 시간) 표시, '차량 보기'로 상세 이동.

  5. **기타**: 운영 상태 칩 문구 변경(정상 운영 / 시범 운영 / 운영 중지), 중복 코드 정리, README에 주행·도착 확인 방법 추가.

     * 주행 중이면 확인 창 후 신고, 신고 시 일시정지·배차 불가.
     * 차량 상세 고장 카드(사유·신고 시각) + 고장 해제 버튼. 고장 기록·사진 첨부는 서버 미지원으로 제외.

  4. **OSM 지도 · 알림 창 정리**:

* **담당 역할**: 앱 프론트엔드 (Figma 화면 디자인, 화면 구현)
* **주요 작업 내용**:

     * 팀 Figma(v2 변수)의 색상·글자 스타일을 디자인 토큰(`src/theme.ts`)으로 옮기고 Noto Sans KR·Inter 글꼴 적용.
     * Figma 아이콘(SVG)을 컴포넌트로 쓰도록 설정(`metro.config.js`, `.svgrrc.js`), NT1 로고·N3 차량 이미지 에셋 추가.
     * API 명세 필드명 기준 차량 타입(`src/types/vehicle.ts`)과 서버 연동 전 임시 데이터(`src/mocks/`) 작성.

  2. **Figma 화면 디자인 추가**:
     * 목적지 선택, 차량 상세(작업 중 · 일시 정지), 작업 더보기 시트, 작업 취소 확인 창.
     * 차량 필터 · 운영 구역 선택, 필터 적용 중 표시, 차량 ID 검색(입력 중 · 결과 · 결과 없음).
     * 주행 유형 선택(작업 수행 / 시범 운행), 작업 경로 설정(출발 · 경유 · 도착), 지점 선택.
     * 공통 컴포넌트: Filter Chip, Outline Button, Indicator Dot, Stop Tag, Stop Row, 아이콘.

  3. **화면 구현 (Android 에뮬레이터 확인)**:
     * **차량 목록**: 차량 카드(상태 칩·위치·거리·배터리·통신 지연), 차량 ID 검색(검색어 강조, 결과 없음 안내), 하단 탭 바.
     * **차량 필터 · 운영 구역 선택**: 항목별 여러 개 선택, 적용 중이면 필터 버튼에 파란 점 표시.
     * **차량 상세**: 대기·작업 중·일시 정지·전원 꺼짐 상태별 화면, 작업 정보 시트, 작업 취소 확인 창, 전원 켜기/끄기.
     * **주행 시작 흐름**: 주행 유형 선택 → 작업 경로 설정(경유지 여러 개) → 지점 선택 → 출발 확인.
     * 서버 연동 전이라 버튼은 화면 안에서만 상태를 바꿈 (`src/mocks/vehicleActions.ts`, 연동 가이드 3.2 상태 규칙 적용).
     * 타입 검사, expo-doctor 20개 검사, Android 번들 빌드 통과.

* **기술적 고민 & 해결 (Troubleshooting)**:
  * **지도 배경**: 앱이 OSM 공식 타일 서버에 직접 요청하면 차단 이미지가 옴(react-native-maps로는 앱 정보 헤더를 바꿀 수 없음).
    CARTO 타일은 API 키가 필요해 제외. 앱 정보 헤더를 넣어 요청하면 OSM이 정상 타일을 주는 것은 확인함.
    → Mock 서버 타일 중계 API로 해결하기로 하고 한정혁 님·서버팀에 요청. 그 전까지는 Google 기본 지도가 배경으로 보임(Expo Go에서 `mapType="none"` 미적용).
  * **거리 기준**: 사용자가 C-Track 밖이거나 위치를 모르면 C-Track 기준점(NT1 11/16 피드백 OSM 링크 좌표)과의 거리를 표시 (연동 가이드 4.1).
  * **필터 규칙**: 같은 항목 안에서는 하나라도 맞으면(OR), 항목끼리는 모두 맞아야(AND) 표시. 운영 구역 목록은 차량들의 `parkName`으로 만들고 시·도/시·군·구는 충청북도 청주시로 고정(구역 목록 API 없음).
  * **경유지**: 서버 `vehicleStart`는 출발→도착만 받으므로 경유지 지원은 서버팀과 협의 필요. 지점 목록도 서버에 없어 임시 데이터(`src/mocks/stations.ts`) 사용.
