## [2026-11-19] 제공 API 명세서 반영 및 지도 좌표 배차 구현

* **담당 역할**: Mock 서버 REST API·인증·실시간 상태 및 관제 대시보드 개발
* **주요 작업 내용**:
  * 제공 API 명세서의 토큰 발급, 공통 Query·SHA-1 서명 및 X 헤더 검증, 차량·작업·경로 조회, 취소·전원 제어 구현. Swagger의 요청·성공·오류 응답 모델과 한국어 설명 반영.
  * 지도 중앙 고정 핀을 통한 목적지 선택, OSM 도로망 위 좌표 보정, 경로 미리보기 및 호출 확정 후 가상 주행 구현. 좌표 배차를 명세의 작업·계획 경로·취소와 Mock 일시정지·재개 API에 연결.
  * 기업 제공 공식 코스가 아닌 임의 순환 코스 제거. 주행 중 목적지 선택 제한, 확정 경로의 보라색 목적지 포인트 및 차량 클릭에 따른 1·2호차 선택·상태·제어 대상 전환 구현.
  * 센서별 상태는 시험용 데이터를 사용하고 제공 이미지의 차량 제원 반영. 실제 하드웨어 연동은 수행하지 않음.
* **기술적 고민 & 해결 (Troubleshooting)**:
  * 고정 정류장 없이 기존 명세와 좌표 배차를 연결하기 위해 작업별 출발·도착 좌표 및 작업 전용 임시 ID 사용. 미리보기와 실제 배차를 분리하고 오래된 응답을 무효화.
  * 차량 선택 시 이전 목적지 미리보기를 취소하고, 배차·주행 제어 대상과 확정 경로를 차량별로 구분.
* **검증 상태**:
  * 최신 전체 pytest 16개 통과. 이전 29개에서 삭제한 임의 코스 전용 테스트 13개 제외.
  * 차량 선택 JavaScript 문법 및 모의 UI 검사 통과. 임시 Uvicorn 기동과 /docs·/openapi.json·/dashboard·/api/routes 정상 응답 확인 후 종료.
  * 실제 브라우저의 전체 동작 및 Android 앱 연동은 미검증. 원본 명세와 지도 좌표계 기준, 정류장 배차 방식의 협의 사항은 남아 있음.
* **다음 작업 계획**:
  * 명세서 기준 필수 기능의 누락 항목 점검 및 미완성 기능 보완.
  * 차량 조회 → 목적지 선택 → 배차 → 주행 → 일시정지·재개·취소·도착 흐름과 차량별 상태·제어 검증.
  * 최근 지도 UI와 차량 전환 기능의 실제 브라우저 검증.
  * Android 앱 연동은 필수 기능 구현을 마친 후 진행.
