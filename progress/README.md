# 📝 개인별 작업 일지 작성 가이드 (Progress Guide)

본 폴더는 각 팀원의 일일 개발 진행 상황, 기술적 고민, 해결 과정, 다음 계획을 기록하는 공간입니다.  
부담 없이 **하루 3~5줄 내외의 핵심 내용**만 기록해 주시면 됩니다.

---

## 📌 일일 일지 작성 템플릿 (복사용)

작업을 마친 날, 본인 파일(`choi_sujeong.md`, `han_seunggyu.md`) 상단에 아래 양식을 복사하여 추가해 주세요.

```markdown
## [YYYY-MM-DD] 작업명 / 요약

* **담당 역할**: (예: 시뮬레이션 / Mock 통신 & API)
* **주요 작업 내용**:
  * 구체적으로 구현하거나 수정한 기능 1
  * 구체적으로 구현하거나 수정한 기능 2
* **기술적 고민 & 해결 (Troubleshooting)**:
  * 발생했던 문제점 또는 설계 고민: 
  * 해결 방법 또는 도출한 결론: 
* **다음 작업 계획**:
  * 다음에 진행할 세부 마일스톤 또는 연동 작업
```

---

## 💡 작성 팁
1. **작성 주기**: 코드를 커밋하고 푸시할 때 함께 작성하는 것을 권장합니다.
2. **커밋 메시지와 연계**: 커밋 메시지에 적기 어려운 상세한 이유나 배경을 여기에 적어두면 12/13 최종 보고서 작성 시 큰 도움이 됩니다.
